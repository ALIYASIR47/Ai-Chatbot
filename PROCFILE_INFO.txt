What is Procfile?
==================

Procfile is a configuration file used by cloud deployment platforms (Heroku, Render, Railway) to specify how to run your application.

Location: Root directory of your project

Format:
-------
process_type: command

Example (our project):
---------------------
web: gunicorn app:app

Explanation:
- "web" = Process type (web server)
- "gunicorn" = Production WSGI server (better than Flask dev server)
- "app:app" = First 'app' is filename (app.py), second 'app' is Flask variable

Why Gunicorn?
-------------
- Flask's built-in server is for development only
- Gunicorn handles multiple requests efficiently
- Required for production deployment
- Supports worker processes for scaling

Alternative Commands:
--------------------
web: python app.py              # Development (not recommended for production)
web: gunicorn app:app           # Production (recommended)
web: gunicorn app:app -w 4      # 4 worker processes
web: gunicorn app:app -b 0.0.0.0:8000  # Specific host:port

Platform Usage:
--------------
1. Heroku: Automatically reads Procfile
2. Render: Uses it if present, otherwise auto-detects
3. Railway: Auto-detects Python and uses Procfile
4. Fly.io: Can use Procfile or fly.toml

Our Procfile Content:
--------------------
web: gunicorn app:app

This tells the platform:
"Run this as a web service using Gunicorn to serve the Flask app"
